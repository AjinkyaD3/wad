10. User Registration Form

Create a "User Registration Form" with the following fields:

a. Name
* Text field

b. Password
* Password field

c. E-mail ID
* Should not contain any invalid format
* Must follow the standard pattern: name@domain.com

d. Phone Number
* Create dropdown for country code
* Mobile number should be 10 digits only

e. Sex
* Radio button

f. Date of Birth
* 3 select boxes

g. Languages Known
* Check boxes:
  * English
  * Marathi
  * Hindi
  * Tamil

h. Address
* Text area
