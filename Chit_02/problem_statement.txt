2. JavaScript Validation for Registration Page

Write JavaScript to validate the following fields of the Registration page:

a. First Name
* Name should contain alphabets only
* Length should not be less than 6 characters

b. Password
* Password should not be less than 6 characters length

c. E-mail ID
* Should not contain any invalid format
* Must follow the standard pattern: name@domain.com

d. Mobile Number
* Phone number should contain 10 digits only

e. Last Name and Address
* Should not be empty
