7. Login Page Validation

Design a Login Page using HTML & CSS to validate the following fields:

a. User Name
* Should contain at least:
  * One BLOCK letter alphabet
  * One small letter alphabet
  * One special character
  * One number
* Length should not be less than 8 characters

b. Password
* Should contain:
  * One BLOCK letter
  * One special character
* Length should not be less than 8 characters
